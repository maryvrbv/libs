# Which Files Do I Need?

40 files is a lot. This guide helps you find the right ones for your situation.

## The Quick Answer

Most marketing tasks need **1-2 files** combined into a single CLAUDE.md:

1. **A content or workflow file** (what you're producing)
2. **A strategy or metrics file** (how you're thinking about it) — optional but makes output sharper

## Common Recipes

Here are the most common marketing workflows and exactly which files to combine:

### Recipe: Launch Campaign

```
go-to-market.md + campaign-brief.md + product-launch-announcement.md + launch-checklist.md
```

Build the GTM strategy, write the campaign brief, draft multi-channel launch copy, run the launch process.

### Recipe: Content Engine

```
content-strategy.md + content-calendar.md + content-led-growth.md + content-repurposing.md
```

Define pillars and audience, plan the editorial calendar, set up the content flywheel, maximize every piece.

### Recipe: Email Growth

```
email-growth.md + lead-magnet.md + email-sequence.md + email-analytics.md
```

Build the list, create the opt-in asset, write the nurture sequence, measure what's working.

### Recipe: Paid Scaling

```
paid-acquisition.md + ad-copy.md + ab-test-design.md + campaign-performance.md
```

Set the channel strategy, write ad variations, design tests, review results with ROI.

### Recipe: Positioning Overhaul

```
positioning-framework.md + competitive-analysis.md + messaging-architecture.md + brand-voice-guide.md
```

Define your category and differentiation, map the competition, build the messaging hierarchy, document the voice.

### Recipe: Growth Sprint

```
marketing-sprint.md + funnel-analysis.md + ab-test-design.md + marketing-metrics.md
```

Set the sprint goal, diagnose the funnel, design experiments, define success metrics.

## How to Combine Files

1. Pick your primary file (usually the content or workflow)
2. Open it in a text editor
3. Open the secondary files you want to add
4. Copy relevant sections from the secondary files into your primary file
5. Remove any duplicate or conflicting sections
6. Save as `CLAUDE.md` in your project root

You don't need to include everything from every file. Just grab the sections that are relevant. More context = better results, but irrelevant context won't hurt.

## Still Not Sure?

**Just starting out?** Use `campaign-brief.md`. It's the most versatile marketing document and the one you'll use most.

**Working on strategy?** Use `positioning-framework.md` + `messaging-architecture.md`. Strategy work needs both the positioning and the messaging.

**Overwhelmed?** Pick ONE file. Any one. Drop it in. Start working. You can always add more later.
