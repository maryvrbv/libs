## Getting Started

1. **New to skill files?** Read `QUICK-START.md` — a step-by-step walkthrough with a real example

3. **Ready to go?** Copy a file into your project root, rename it `CLAUDE.md`, and start working

## How to Use

1. **Pick the file(s)** that match what you're doing (see `PICKER.md` for help)
2. **Copy** into your project's root directory
3. **Rename** to `CLAUDE.md`
4. **Customize** the project-specific sections (marked with `[brackets]`) — optional, but makes Claude more precise
5. **Start working** — Claude now thinks like a marketer

**Combining files:** Most marketing workflows use 1-3 files merged together. Writing a campaign brief? Start with `campaign-brief.md`, pull in the messaging section from `messaging-architecture.md`, and add the metrics framework from `marketing-metrics.md`. See `PICKER.md` for common recipes.

## Tips

- **Edit the `[brackets]`.** Each file works out of the box, but filling in your product details makes Claude even better.
- **Keep it updated.** As your campaigns evolve, update the context sections.
- **Works with any Claude Code plan.** These are just markdown files — no special tooling needed.
- **More context = better output.** Don't worry about the file being too long — Claude reads the whole thing.
