# Типограф сайта

Прогоняет весь видимый текст HTML-страниц сайта через правила русской типографики
[SBOL Typograph](https://github.com/DanilovM/SBOLTypographFigma): неразрывные пробелы,
правильные тире (длинное/короткое/неразрывный дефис), «ёлочки», разбивка чисел и т.д.

## Как запустить

```bash
node tools/typograf/apply-to-html.js index.html case-alfa.html case-alfa-research.html \
  case-megafon.html case-loyalty.html case-training.html styleguide.html
```

Можно передать любой список `.html`-файлов сайта — правит их на месте (`git diff` покажет
изменения перед коммитом). Обязательно проверяй diff после запуска: инструмент трогает только
текст, но лучше свериться глазами, особенно если добавился новый текст с числами/валютой.

## Как это устроено

- `typograf-core-lib.js` — ядро типографа (`applyTypograph`), взято из скомпилированного
  `code.js` оригинального Figma-плагина. Ёфикатор (замена «е» → «ё») отключён — ему нужен
  огромный словарь и это семантически рискованно применять автоматически.
- `post-fix.js` — два патча для багов самой библиотеки, найденных при первом прогоне (см. ниже).
- `apply-to-html.js` — раннер: разбивает HTML на токены (теги/комментарии/`<script>`/`<style>`/
  `<code>` — не трогает; текстовые узлы между тегами — прогоняет через типограф), с двумя
  дополнительными защитами:
  - границы текстового узла (пробел перед/после соседнего тега) не трогает, чтобы не склеить
    слова на стыке с инлайновым тегом;
  - подстроки вида `--css-var-name` (CSS-переменные, `.class--modifier`) защищены от того, чтобы
    типограф прочитал `--` как тире.

## Известные баги библиотеки (обойдены в `post-fix.js`)

1. **Точка после млн/млрд/трлн/$/€/₽ в конце строки пропадает.** У библиотеки есть правило
   «не убирай точку, если сокращение — последнее в предложении», но из-за особенности движка
   регулярных выражений V8 (необязательная группа с единственно возможным нулевой-длины
   совпадением `$` даёт `undefined`, а не `""`) это правило срабатывает наоборот. Проявляется
   почти всегда, потому что в HTML каждый текстовый узел — отдельная «строка».
2. **Ложные диапазоны чисел на акронимах.** Правило для диапазонов («2002–2009», «XI–XII»)
   ищет букву рядом с тире, включая буквы, которые совпадают с латинскими «римскими цифрами»
   (I, V, X, L, C, D, M). Акроним, оканчивающийся на одну из них (например `BNPL`), рядом с
   цифрой через тире ошибочно распознаётся как численный диапазон:
   `BNPL — 34%` → `BNPL–34%` вместо `BNPL — 34%`.

Оба фикса не патчат сложный регекс библиотеки, а исправляют результат постфактум — так безопаснее
и понятнее, если апстрим когда-нибудь исправит баги сам.
