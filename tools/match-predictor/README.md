# Прогноз футбольных матчей

Предсказывает исходы (П1 / X / П2), ожидаемые голы, вероятные счета, тотал 2,5 и «обе забьют»
по истории результатов. Данные — бесплатные CSV с [football-data.co.uk](https://www.football-data.co.uk)
(результаты и коэффициенты 16 европейских лиг, обновляются пару раз в неделю). Чистый Python 3.10+,
без зависимостей.

## Как запустить

```bash
cd tools/match-predictor

python3 -m matchpredictor ratings                       # сила команд АПЛ
python3 -m matchpredictor predict Arsenal "Man City"    # один матч
python3 -m matchpredictor fixtures --league SP1         # ближайшие матчи Ла Лиги
python3 -m matchpredictor backtest --seasons 2223 2324 2425   # проверка на истории
```

Общие флаги: `--league` (E0, E1, D1, I1, SP1, F1, N1, P1, T1… — полный список в `--help`),
`--seasons` (по умолчанию последние три), `--csv` (свои файлы вместо скачивания),
`--elo-weight`, `--json`. Скачанные сезоны кэшируются в `~/.cache/matchpredictor`,
текущий сезон и расписание перекачиваются при каждом запуске.

Пример вывода:

```
Arsenal — Man City
  xG: 1.40 : 1.04
  П1  42.7%   X  29.1%   П2  28.3%
  Тотал больше 2,5:  44.1%   Обе забьют:  49.9%
  Вероятные счета: 1:1 (13.8%), 1:0 (11.0%), 0:0 (9.8%)
```

Из Python:

```python
from matchpredictor import MatchPredictor, load_league

matches = load_league("E0", ["2425", "2526", "2627"])
model = MatchPredictor().fit(matches)
p = model.predict("Arsenal", "Chelsea")
print(p.p_home, p.p_draw, p.p_away, p.top_scores)
```

## Как это устроено

- **Диксон — Коулз** (`poisson.py`) — основная модель. У каждой команды атака и оборона; голы
  хозяев ~ Пуассон(μ · дом · атака · слабость обороны соперника). Старые матчи весят меньше
  (полураспад 500 дней), каждая команда притянута к среднему двумя «псевдоголами», поэтому
  пара случайных результатов не даёт экстремальных рейтингов. Поправка rho исправляет частоту
  счетов 0:0, 1:0, 0:1, 1:1. Команды, появившиеся в данных позже (новички лиги), стартуют
  с приором слабее среднего.
- **Эло** (`elo.py`) — рейтинг с учётом разницы мячей и откатом к среднему между сезонами.
  Разница рейтингов переводится в П1/X/П2 упорядоченной логистической регрессией, обученной
  на прошлых матчах.
- **Ансамбль** (`model.py`) — 80% Диксон — Коулз + 20% Эло.
- **Бэктест** (`backtest.py`) — walk-forward: каждая неделя предсказывается моделью, обученной
  только на матчах до неё. Метрики: RPS (стандарт для футбола), log-loss, Brier, точность,
  калибровка; сравнение с базовой частотой исходов и с закрывающей линией Pinnacle.

Параметры подобраны на сезоне 2023/24 АПЛ и проверены на отложенном 2024/25 в четырёх лигах.

## Насколько это точно

Тест на сезоне 2024/25 (380 матчей каждой лиги, RPS — меньше лучше):

| Лига | Ансамбль | Эло | Базовая частота | Рынок (закрытие) |
|------|---------:|----:|----------------:|-----------------:|
| АПЛ (E0) | 0.2023 | 0.2052 | 0.2364 | 0.1961 |
| Бундеслига (D1) | 0.2115 | 0.2165 | 0.2379 | 0.2019 |
| Серия A (I1) | 0.1909 | 0.1921 | 0.2288 | 0.1841 |
| Ла Лига (SP1) | 0.1954 | 0.1971 | 0.2289 | 0.1875 |

Модель угадывает исход в ~53% матчей АПЛ против 41% у «всегда хозяева» и хорошо откалибрована:
когда она даёт 60–70%, событие случается в ~60%. Но **рынок точнее**: закрывающие коэффициенты
учитывают составы, травмы, мотивацию и деньги профессиональных игроков, а модель видит только счета.

Ставки на «перевес» в бэктесте не окупаются: при пороге 5% ROI от +1% до −14%, при пороге 15%
ещё хуже. Чем сильнее модель расходится с рынком, тем чаще ошибается именно она. Это инструмент
для аналитики и ориентира, а не способ заработать на ставках.

## Что можно улучшить

- xG вместо голов (Understat, FBref) — самый большой прирост точности для таких моделей.
- Составы и травмы, усталость (плотность календаря), смена тренера.
- Обучение на всех лигах страны сразу, чтобы новички приходили со своей силой из низшей лиги.
- Рыночные коэффициенты как признак — комбинация модели и рынка обычно лучше каждого по отдельности.
