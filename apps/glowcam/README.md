# GlowCam

Приложение для Mac, которое в реальном времени убирает синяки под глазами и выравнивает тон кожи на камере. Работает на вашем компьютере, видео никуда не отправляется.

## Что делает

| Ползунок | Что происходит |
|---|---|
| **Синяки под глазами** | Находит зону под нижним веком и высветляет только то, что темнее окружающей кожи. Заодно убирает синеватый и коричневый оттенок. Ресницы и сами глаза не трогает. |
| **Ровный тон** | Сглаживает покраснения и пятна: подтягивает цвет каждого участка к среднему цвету вашей же кожи. Объём лица (свет и тени) остаётся. |
| **Гладкость кожи** | Мягкое размытие только по коже, с сохранением контуров. |
| **Сохранить текстуру** | Возвращает поры поверх сглаживания, чтобы не было «пластикового» лица. Чем больше, тем естественнее. |
| **Свет на лице** | Мягкая подсветка лица, фон не меняется. |
| **Теплота** | Сдвиг всей картинки в тёплую или холодную сторону. |

Глаза, брови, губы и фон не обрабатываются. Лицо находится по 478 точкам (MediaPipe Face Landmarker), обработка идёт на видеокарте.

## Установка

1. Нужен **Google Chrome** (подойдут также Edge, Brave, Arc).
2. Распакуйте `GlowCam-mac.zip` и перетащите **GlowCam** в папку «Программы».
3. Первый запуск: macOS скажет, что разработчик не проверен (приложение не подписано в Apple). Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **«Всё равно открыть»**.
   Если кнопки нет, выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/GlowCam.app
   ```
4. Разрешите доступ к камере, когда спросит.

Если OBS не установлен, GlowCam откроется отдельным окном в Chrome, только для просмотра. Можно закрепить в Dock.

## Как использовать в Zoom, Google Meet, Telegram

Звонилкам нужна «камера». Её даёт бесплатный **OBS Studio**, а GlowCam работает прямо внутри OBS. Отдельного окна нет, поэтому сворачивать нечего.

### Один раз

1. Установите OBS с https://obsproject.com в папку «Программы» и разрешите его виртуальную камеру: «Системные настройки → Основные → Объекты входа и расширения → Расширения камеры → OBS».
2. Откройте **GlowCam**. Он запустит OBS (если OBS был открыт, перезапустит).
3. В OBS: **Источники → + → Браузер**, назовите «GlowCam».
   - Поставьте галочку **«Локальный файл»** → «Обзор» → ваша домашняя папка → **GlowCam → glowcam.html**.
   - Ширина **1280**, высота **720**. Нажмите «ОК».
   - Если раньше добавляли «Захват экрана macOS» с окном GlowCam, удалите этот источник.
4. Выделите источник GlowCam и нажмите **⌘F**, чтобы он занял весь кадр.
5. Если macOS спросит доступ OBS к камере, разрешите.

### Перед каждым звонком

1. Откройте **GlowCam** (из Dock или «Программ»). Откроется OBS.
2. В OBS нажмите **«Запустить виртуальную камеру»**. После этого OBS можно свернуть (⌘M): камера продолжит работать.
3. В Zoom, Meet или Telegram выберите камеру **OBS Virtual Camera**.

Запускайте OBS именно через GlowCam: если открыть OBS напрямую, у GlowCam внутри не будет доступа к камере.

### Как менять настройки

В OBS нажмите правой кнопкой на источник GlowCam → **«Взаимодействовать»**. В открывшемся окне нажмите **H**: появится панель с ползунками. Настройте и снова нажмите **H**. Настройки сохраняются.

## Клавиши

- **Пробел** (удерживать): показать оригинал
- **H**: спрятать или вернуть панель
- **M**: показать, какие зоны обрабатываются

## Советы

- Начните с пресета «Естественно» и прибавляйте «Синяки под глазами». На слабом свете синяки видны сильнее: лампа или окно перед лицом помогает больше любой ретуши.
- «Сохранить текстуру» не ниже 35, иначе кожа выглядит неестественно.
- Нужен интернет при запуске: модель распознавания лица загружается из сети.

## Для разработчика

`index.html` — всё приложение. После изменений запустите `./build.sh`: он скопирует файл в `GlowCam.app` и соберёт `GlowCam-mac.zip`.
